## ✏️ O que aprendi hoje

<!-- Escreve aqui as tuas notas. Exemplos: -->

- **Aritméticos:** `+`, `-`, `*`, `/`, `//`, `%`, `**`
- **Comparação:** `==`, `!=`, `>`, `<`, `>=`, `<=`
- **Lógicos:** `and`, `or`, `not`
- **Atribuição:** `=`, `+=`, `-=`, `*=`, `/=`
- O operador `//` faz divisão inteira (floor division)
- O operador `**` é a potência (`2 ** 3 == 8`)

---

## 📌 Snippets úteis

```python
# Aritméticos
print(10 // 3)   # 3  (divisão inteira)
print(10 % 3)    # 1  (resto)
print(2 ** 8)    # 256 (potência)

# Comparação
print(10 > 5)    # True
print(10 == 10)  # True

# Lógicos
print(True and False)  # False
print(True or False)   # True
print(not True)        # False
```
